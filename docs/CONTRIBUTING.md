# Contributing

This is a personal portfolio project. External contributions are not currently accepted.

## For the Maintainer

### Workflow

This project is built in phases. Each phase is:

1. Developed
2. Tested by the maintainer
3. Committed with a clear message
4. Only then the next phase begins

### Commit Convention

We follow [Conventional Commits](https://www.conventionalcommits.org/):

| Prefix | Use For |
|--------|---------|
| `feat:` | New feature |
| `fix:` | Bug fix |
| `style:` | Styling changes |
| `chore:` | Config, dependencies, docs |
| `docs:` | Documentation only |
| `refactor:` | Code cleanup |
| `perf:` | Performance |

### Testing Before Commit

- Open `index.html` in browser
- Test desktop and mobile viewport
- Check console (F12) for errors
- Verify all links work
